Guía de estudio: Servidores y servicios de infraestructura

Preparación para examen de opción múltiple sobre instalación de Debian como servidor, servidores web, bases de datos, lenguajes de programación, aplicaciones web open source, correo electrónico, archivos y servidores de aplicaciones.

Propósito de la guía

Repasar los conceptos principales de los servicios instalados y configurados en prácticas de laboratorio, identificando su función dentro del modelo cliente-servidor, sus características, protocolos relacionados, componentes de despliegue y diferencias principales entre tecnologías.

Resultado esperado: el estudiante debe reconocer qué servicio se utiliza, para qué sirve, con qué protocolos trabaja, qué componentes requiere y cómo se integra en una solución web o de infraestructura.

1. Debian GNU/Linux como sistema operativo servidor

Definición

Debian GNU/Linux es una distribución de sistema operativo libre basada en el kernel Linux. En un servidor, funciona como plataforma base para instalar, configurar y administrar servicios como servidores web, bases de datos, correo, archivos y aplicaciones.

Sistema operativoLinuxServidorSoftware libre

Características principales

  • Estabilidad y seguridad para entornos de producción y laboratorio.
  • Administración mediante terminal y comandos.
  • Gestión de paquetes con apt.
  • Control de servicios con systemctl.
  • Uso de usuarios, grupos y permisos para proteger archivos y procesos.

Conceptos que debe dominar el estudiante

  • Kernel, distribución, repositorio, paquete, servicio y demonio.
  • Directorios importantes: /etc, /var, /home, /usr, /opt, /root y /tmp.
  • Comandos básicos: pwd, ls, cd, mkdir, cp, mv, rm, chmod, chown, sudo, apt y systemctl.

2. Modelo cliente-servidor y protocolos base

El modelo cliente-servidor organiza la comunicación entre un cliente que solicita un recurso o servicio y un servidor que procesa la solicitud y devuelve una respuesta. La comunicación ocurre mediante direcciones IP, nombres de dominio, puertos y protocolos.

ServidorEquipo o software que atiende solicitudes y ofrece recursos.Apache, Nginx, MySQL, Postfix.
IPDirección lógica que identifica un equipo en una red.192.168.1.10

3. Servidores web: Apache y Nginx

Apache HTTP Server

Apache es un servidor web que recibe solicitudes HTTP o HTTPS y entrega páginas web, archivos estáticos o respuestas generadas por aplicaciones. Es muy utilizado por su compatibilidad, modularidad y facilidad de integración con PHP.

  • Usa archivos de configuración y sitios virtuales.
  • Puede trabajar con módulos como mod_php, mod_ssl y mod_rewrite.
  • Su directorio raíz común en Debian es /var/www/html.
  • Permite alojar varios sitios mediante Virtual Hosts.

Nginx

Nginx es un servidor web de alto rendimiento, frecuentemente usado para servir contenido estático, actuar como proxy inverso, balanceador de carga y puerta de entrada hacia aplicaciones ejecutadas por Gunicorn, PHP-FPM u otros servicios.

  • Utiliza una arquitectura eficiente basada en eventos.
  • Consume pocos recursos en comparación con modelos tradicionales por proceso.
  • Es común en despliegues modernos en la nube.
  • Puede reenviar solicitudes a Gunicorn, Tomcat u otros servidores internos.

Uso comúnSitios PHP, CMS, hosting tradicional.Proxy inverso, alto rendimiento, nube.
Integración con PHPPuede usar mod_php o PHP-FPM.Usa normalmente PHP-FPM.

4. Lenguajes de programación web: PHP y Python

PHP

PHP es un lenguaje de programación del lado del servidor orientado principalmente al desarrollo web. Se ejecuta en el servidor, genera contenido dinámico y puede conectarse con bases de datos como MySQL o PostgreSQL.

  • Muy usado en aplicaciones open source como WordPress, Moodle, PrestaShop y Nextcloud.
  • Puede ejecutarse con Apache mediante módulos o con Nginx/Apache mediante PHP-FPM.
  • Permite mezclar código con HTML para generar páginas dinámicas.

Python

Python es un lenguaje interpretado, de sintaxis clara y uso general. En servidores web se utiliza con frameworks como Flask o Django para construir aplicaciones dinámicas conectadas a bases de datos.

  • Se usa en desarrollo web, automatización, ciencia de datos e inteligencia artificial.
  • Las aplicaciones Flask suelen ejecutarse mediante Gunicorn y publicarse detrás de Nginx.
  • Su ecosistema permite instalar librerías con pip y aislar proyectos con venv.

5. Servidores de bases de datos

MySQL

MySQL es un sistema gestor de bases de datos relacional. Organiza la información en tablas, registros, columnas y relaciones. Es común en aplicaciones web PHP y plataformas como WordPress y PrestaShop.

  • Utiliza SQL para crear, consultar, modificar y administrar datos.
  • Trabaja con claves primarias y foráneas.
  • Es frecuente en la pila LAMP/LEMP.

PostgreSQL

PostgreSQL es un sistema gestor de bases de datos relacional avanzado, reconocido por su integridad, apego a estándares SQL, soporte para transacciones y extensibilidad.

  • Soporta transacciones ACID.
  • Puede manejar datos relacionales y tipos avanzados como JSON.
  • Es apropiado para aplicaciones que requieren consistencia y reglas complejas.

MongoDB

MongoDB es una base de datos NoSQL orientada a documentos. En lugar de almacenar datos en tablas, utiliza documentos con estructura similar a JSON y los agrupa en colecciones.

  • Documento: estructura flexible parecida a JSON.
  • Colección: conjunto de documentos relacionados.
  • BSON: formato binario usado internamente para almacenar documentos.
  • No requiere un esquema rígido como una base relacional tradicional.
Ejemplo conceptual: { "nombre": "Ana", "edad": 18, "curso": "Servidores" }

6. Aplicaciones web open source en despliegue

WordPress

WordPress es un CMS, es decir, un sistema de gestión de contenidos. Permite crear sitios web, blogs, páginas institucionales y portales mediante temas, plugins, entradas y páginas.

  • Usa principalmente PHP y MySQL/MariaDB.
  • Permite ampliar funciones mediante plugins.
  • Es útil para comprender despliegue de CMS en servidores web.

Moodle

Moodle es un LMS, es decir, una plataforma para administrar cursos, usuarios, actividades, recursos, evaluaciones y seguimiento del aprendizaje.

  • Se utiliza en educación presencial, híbrida y virtual.
  • Requiere servidor web, PHP y base de datos.
  • Maneja roles como administrador, profesor y estudiante.

PrestaShop

PrestaShop es una aplicación web open source para comercio electrónico. Permite crear tiendas en línea con catálogo de productos, carrito de compras, pedidos, clientes, pagos y administración de inventario.

  • Usa PHP y base de datos MySQL/MariaDB.
  • Permite gestionar productos, categorías, clientes y pedidos.
  • Es útil para estudiar aplicaciones web con front office y back office.
AplicaciónTipoFinalidadTecnologías comunes
WordPressCMSCrear y administrar sitios web.PHP + MySQL + Apache/Nginx.
MoodleLMSAdministrar cursos y aprendizaje.PHP + MySQL/PostgreSQL + Apache/Nginx.

7. Nextcloud como servidor de archivos

Definición

Nextcloud es una plataforma open source para crear una nube privada de archivos. Permite almacenar, sincronizar, compartir y administrar documentos desde una interfaz web o aplicaciones cliente.

Características

  • Gestión de usuarios y permisos.
  • Compartición de archivos y carpetas.
  • Acceso vía navegador y clientes de sincronización.
  • Integración con calendario, contactos y extensiones.

8. Correo electrónico: Postfix y Thunderbird

Postfix

Postfix es un servidor de correo que cumple la función de MTA, es decir, agente de transferencia de correo. Su tarea principal es enviar, recibir y enrutar mensajes mediante el protocolo SMTP.

  • SMTP se usa para enviar y transferir correos entre servidores.
  • Puede combinarse con Dovecot para ofrecer acceso IMAP o POP3 al buzón.
  • Puede integrarse con clientes de correo como Thunderbird.

Agentes del correo

  • MUA: Mail User Agent, aplicación cliente usada por el usuario.
  • MSA: Mail Submission Agent, recibe el correo enviado por el usuario.
  • MTA: Mail Transfer Agent, transfiere correos entre servidores.
  • MDA: Mail Delivery Agent, entrega el mensaje al buzón local.

Thunderbird

Thunderbird es una aplicación cliente de correo electrónico. Permite al usuario configurar cuentas, enviar mensajes por SMTP y recibir mensajes mediante IMAP o POP3.

  • No es servidor, es cliente de correo.
  • Permite probar cuentas creadas en el servidor.
  • Puede configurarse con servidor entrante IMAP/POP3 y servidor saliente SMTP.

9. Servidores de aplicaciones: Gunicorn y Tomcat

Gunicorn

Gunicorn es un servidor de aplicaciones Python compatible con WSGI. Se utiliza para ejecutar aplicaciones web creadas con frameworks como Flask o Django.

  • WSGI es una especificación que permite comunicar servidores web con aplicaciones Python.
  • Gunicorn ejecuta la aplicación y atiende solicitudes mediante procesos llamados workers.
  • Normalmente se coloca detrás de Nginx, que recibe la solicitud pública y la reenvía a Gunicorn.
Cliente → Nginx → Gunicorn → Aplicación Flask → Base de datos

Apache Tomcat

Apache Tomcat es un servidor de aplicaciones Java. Funciona como contenedor de Servlets y permite ejecutar aplicaciones web desarrolladas con tecnologías Java.

  • Servlet: componente Java que procesa solicitudes y genera respuestas.
  • JSP: JavaServer Pages, tecnología para crear páginas web dinámicas con Java.
  • Tomcat no es lo mismo que Apache HTTP Server; Apache HTTP Server es principalmente servidor web, mientras que Tomcat ejecuta aplicaciones Java.
Cliente → Tomcat → Aplicación Java → Base de datos
