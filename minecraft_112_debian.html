Minecraft 1.12.2 en Debian 12: servidor y cliente

Referencia de laboratorio · Administración y Configuración Cliente/Servidor

Esta guía instala en una misma VM Debian 12 el servidor oficial de Minecraft Java Edition 1.12.2, con Java 8 y como servicio de systemd, y el cliente con el launcher oficial sobre un escritorio XFCE. Se eligió la 1.12.2 porque corre en equipos con Core i3 y gráficos integrados. Al final podrás jugar en tu propio servidor y entrar al de cualquier compañero por el puerto TCP 25565.

Es el mismo modelo que siguen los juegos en línea más jugados: un servidor autoritativo que calcula el estado de la partida y clientes que solo envían acciones y muestran el resultado.

Qué es un servidor de Minecraft Java

Minecraft Java Edition separa el juego en dos programas: el cliente, que cada jugador instala en su computadora y que renderiza el mundo, y el servidor (server.jar), que Mojang distribuye gratis y que calcula el estado real de la partida. El servidor es autoritativo: los clientes solo envían sus acciones y el servidor decide qué pasa.

1.12.2
Versión de 2017, la última de la serie 1.12. Es ligera y funciona con Java 8 en equipos sin tarjeta gráfica dedicada.
server.jar
Programa servidor oficial de Mojang, escrito en Java.
TCP 25565
Puerto y protocolo predeterminados de Minecraft Java Edition.
Tick
Cada ciclo en que el servidor recalcula el mundo. Minecraft trabaja a 20 ticks por segundo.
EULA
Acuerdo de licencia de Mojang que hay que aceptar antes de arrancar el servidor.
Temurin 8
Distribución gratuita de OpenJDK 8 del proyecto Eclipse Adoptium.

Antes de empezar

En esta práctica cada alumno tiene en su misma VM el servidor y el cliente: puede jugar en su propio mundo y también entrar al servidor de cualquier compañero. Los recursos se reparten así:

Debian + XFCE~1 GBEscritorio ligero
Servidor 1.12.21 GB-Xmx1G

Total de la VM6 GB · 2 CPUCon 12 GB en la PC, quedan 6 GB para Windows
  • Para jugar, cada alumno necesita una cuenta de Minecraft Java Edition con licencia. El servidor es gratis; el cliente no. Quien no tenga cuenta monta su servidor y lo comprueba con mcstatus (paso 11); sus compañeros con cuenta pueden entrar a jugar en él.
  • La PC no tiene tarjeta gráfica dedicada, pero el i3 sí tiene gráficos integrados; VirtualBox los aprovecha con la aceleración 3D (paso 10.1).
  • Si ya instalaste Tomcat, no hay conflicto: Tomcat sigue con OpenJDK 17 y Minecraft usa su propio Java 8 por ruta completa.

¿Qué es systemd?

Es el programa que Debian ejecuta primero al encender (el proceso con PID 1) y que arranca, vigila y detiene todos los servicios del sistema: SSH, Apache, MySQL, Tomcat. Cada servicio se describe en un archivo .service que indica qué programa ejecutar, con qué usuario y qué hacer si falla. En esta guía crearás minecraft.service (paso 7.2) para que el servidor arranque solo con la VM, se reinicie si se cae y se controle igual que los demás servicios: systemctl start, stop, status y journalctl -u minecraft para su bitácora.

Seguridad: versión antigua, solo en la red del laboratorio

La 1.12.2 ya no recibe actualizaciones. En 2021 se descubrió una falla grave en la librería Log4j que usa el servidor; Mojang publicó un archivo de configuración que la corrige y esta guía lo descarga en el paso 5.2 y lo aplica en el arranque (pasos 6 y 7). Aun así, no publiques este servidor en internet: úsalo solo dentro de la red del laboratorio.

1. Actualizar el sistema

1.1

Actualizar e instalar herramientas

Se actualizan los paquetes y se instalan las utilidades para descargar archivos y leer JSON.

$sudo apt update
$sudo apt upgrade -y
$sudo apt install -y wget curl jq gpg

jq sirve para leer archivos JSON desde la terminal; lo usaremos para consultar la información oficial de Mojang.

2. Consultar qué Java pide la 1.12.2

2.1

Java requerido

Mojang publica un manifiesto JSON con todas las versiones. Se busca la 1.12.2 y se lee qué versión de Java necesita.

$VERSION_URL=$(curl -fsSL https://piston-meta.mojang.com/mc/game/version_manifest_v2.json | jq -r '.versions[] | select(.id == "1.12.2") | .url')
$echo "$VERSION_URL"

Debe mostrar una dirección https que termina en .json.

$curl -fsSL "$VERSION_URL" | jq '.javaVersion.majorVersion'

Resultado esperado: 8. Por eso no sirve el Java 17 de Debian ni el 21: esta versión se hizo para Java 8.

⚠ La variable VERSION_URL solo existe en esta sesión de terminal. Si la cierras, repite este paso antes del paso 5.

3. Instalar Java 8 (Temurin)

3.1

Agregar el repositorio de Adoptium

Debian 12 ya no trae Java 8. Se importa la llave GPG con la que Adoptium firma sus paquetes y se registra su repositorio para Debian 12 (bookworm).

$wget -qO - https://packages.adoptium.net/artifactory/api/gpg/key/public | gpg --dearmor | sudo tee /etc/apt/trusted.gpg.d/adoptium.gpg > /dev/null

La llave permite que apt verifique que los paquetes realmente vienen de Adoptium.

$echo "deb https://packages.adoptium.net/artifactory/deb bookworm main" | sudo tee /etc/apt/sources.list.d/adoptium.list
3.2

Instalar el JRE 8

Para ejecutar el servidor basta el JRE (entorno de ejecución); no hace falta el JDK completo.

$sudo apt update
$sudo apt install -y temurin-8-jre
3.3

Verificar la ruta de Java 8

Se comprueba dónde quedó instalado. Esa ruta completa se usará en el servicio.

$ls /usr/lib/jvm/

Debe aparecer temurin-8-jre-amd64. Si ya tenías Tomcat, también verás la carpeta de OpenJDK 17.

$/usr/lib/jvm/temurin-8-jre-amd64/bin/java -version

Resultado esperado: openjdk version "1.8.0_…". Java 8 se numera como 1.8.

4. Crear el usuario del servicio

4.1

Usuario minecraft

Como con Tomcat, el servidor no corre como root: si alguien explotara una falla del juego, solo tendría los permisos de este usuario.

$sudo useradd -r -m -U -d /opt/minecraft -s /bin/false minecraft

-r crea una cuenta de sistema, -d /opt/minecraft la usa como carpeta del servidor y -s /bin/false impide iniciar sesión con ella.

5. Descargar el servidor 1.12.2

5.1

Descargar server.jar

Del JSON de la versión se obtiene la dirección oficial del servidor y se descarga en /opt/minecraft como el usuario minecraft.

$SERVER_URL=$(curl -fsSL "$VERSION_URL" | jq -r '.downloads.server.url')
$sudo -u minecraft curl -fLo /opt/minecraft/server.jar "$SERVER_URL"

sudo -u minecraft hace que el archivo nazca con el dueño correcto, sin necesidad de chown.

5.2

Descargar el parche de Log4j

Archivo oficial de Mojang para las versiones 1.12 a 1.16.5. Va en la misma carpeta que server.jar.

$sudo -u minecraft curl -fLo /opt/minecraft/log4j2_112-116.xml https://launcher.mojang.com/v1/objects/02937d122c86ce73319ef9975b58896fc1b491d1/log4j2_112-116.xml
$ls -lh /opt/minecraft/

Deben aparecer server.jar (unos 30 MB) y log4j2_112-116.xml.

6. Primer arranque y EULA

6.1

Arranque de prueba

La primera ejecución crea los archivos de configuración y se detiene sola, porque todavía no se ha aceptado la licencia.

$sudo -u minecraft bash -c 'cd /opt/minecraft && /usr/lib/jvm/temurin-8-jre-amd64/bin/java -Xms512M -Xmx1G -Dlog4j.configurationFile=log4j2_112-116.xml -jar server.jar nogui'

-Xms512M es la memoria inicial y -Xmx1G la máxima. -Dlog4j.configurationFile aplica el parche de seguridad. nogui evita que intente abrir una ventana.

6.2

Aceptar la EULA

El servidor no arranca hasta que eula.txt diga true. Al cambiarlo aceptas los términos de Mojang (minecraft.net/eula).

$sudo sed -i 's/eula=false/eula=true/' /opt/minecraft/eula.txt
$cat /opt/minecraft/eula.txt

La última línea debe decir eula=true.

7. Configurar y crear el servicio systemd

7.1

Ajustar server.properties

Archivo principal de configuración del servidor. Busca y cambia solo estas líneas; deja el resto igual.

$sudo nano /opt/minecraft/server.properties

/opt/minecraft/server.properties (solo las líneas a revisar)

motd=Servidor del laboratorio 1.12.2
max-players=20
gamemode=0
difficulty=2
online-mode=true
white-list=false
server-port=25565
view-distance=6

En la 1.12 el modo y la dificultad van en número: gamemode 0 supervivencia, 1 creativo; difficulty 0 pacífico a 3 difícil. online-mode=true exige cuentas con licencia: no lo cambies. view-distance=6 reduce la carga de la VM.

7.2

Archivo del servicio

Igual que con Tomcat, se le indica a systemd cómo iniciar el servidor. La diferencia: aquí Java corre en primer plano, por eso no se usa Type=forking.

$sudo nano /etc/systemd/system/minecraft.service

/etc/systemd/system/minecraft.service

[Unit]
Description=Servidor de Minecraft Java 1.12.2
After=network.target

[Service]
User=minecraft
Group=minecraft
WorkingDirectory=/opt/minecraft
ExecStart=/usr/lib/jvm/temurin-8-jre-amd64/bin/java -Xms512M -Xmx1G -Dlog4j.configurationFile=log4j2_112-116.xml -jar server.jar nogui
Restart=on-failure
SuccessExitStatus=0 143

[Install]
WantedBy=multi-user.target

ExecStart usa la ruta completa de Java 8 para no depender del Java predeterminado, e incluye el parche de Log4j. SuccessExitStatus=143 indica que salir por la señal de detener (SIGTERM) es normal; el servidor guarda el mundo antes de cerrar.

7.3

Activar el servicio

Recargar systemd, iniciar el servidor y habilitarlo al arranque.

$sudo systemctl daemon-reload
$sudo systemctl enable --now minecraft

--now lo inicia en este momento además de habilitarlo.

8. Red y puerto

8.1

Cortafuegos

Se permite el tráfico TCP al puerto 25565 para que los compañeros puedan entrar. Si ufw está activo, asegúrate de no cerrar SSH.

$sudo ufw allow OpenSSH
$sudo ufw allow 25565/tcp
$sudo ufw status
8.2

Modo de red de la VM

Para entrar al servidor de un compañero, las VMs deben verse en la red. Hay dos casos.

LaboratorioConfiguración en VirtualBoxA qué IP se conectan los compañeros
Con DHCPRed → Adaptador 1 → Adaptador puente (recomendado)La IP de la VM del compañero (paso 9.2)
Sin DHCP (IP fija)Red → NAT → Avanzadas → Reenvío de puertos: TCP, anfitrión 25565, invitado 25565La IP de la PC del compañero, no la de su VM

Para entrar a tu propio servidor desde tu cliente, en cualquiera de los dos casos usa localhost.

9. Verificar el servicio

9.1

Estado, puerto y bitácora

Confirmar que el servidor está activo, escuchando en TCP 25565, y seguir su bitácora en vivo.

$sudo systemctl status minecraft --no-pager

Resultado esperado: active (running).

$sudo ss -tlnp | grep ':25565 '

Debe aparecer una línea LISTEN con :25565 del proceso java.

$sudo journalctl -u minecraft -f

Espera la línea Done (…s)! For help, type "help": el mundo terminó de generarse. Sal con Ctrl+C; el servidor sigue corriendo.

9.2

IP del servidor

Obtén la IP de la VM para compartirla con tus compañeros.

$ip -br a

Usa la IP de la interfaz enp0s3 (o similar). En NAT, usa la IP de la computadora anfitriona.

10. Instalar el cliente en la misma VM

10.1

Ajustar la VM en VirtualBox

Con la VM apagada, en Configuración. Estos cambios dan memoria al cliente y activan los gráficos 3D.

SecciónValor
Sistema → Placa baseMemoria base: 6144 MB
Sistema → Procesador2 CPU
Pantalla → PantallaMemoria de video: 128 MB · Controlador gráfico: VMSVGA · ☑ Habilitar aceleración 3D
Red → Adaptador 1Según el paso 8.2
10.2

Instalar el escritorio XFCE

Si tu VM solo tiene terminal, se instala un escritorio ligero. Si ya tiene uno (GNOME, XFCE), salta este paso.

$sudo apt install -y xorg xfce4 xfce4-terminal lightdm

XFCE consume poca memoria; lightdm es la pantalla de inicio de sesión. La descarga es grande: unos minutos.

$sudo systemctl set-default graphical.target

Hace que la VM arranque en modo gráfico.

$sudo reboot
10.3

Instalar las Guest Additions

Controladores de VirtualBox para la VM: activan la aceleración 3D y permiten cambiar la resolución de la ventana.

Primero, en el menú de la ventana de VirtualBox: Dispositivos → Insertar imagen de CD de las «Guest Additions». Después, en una terminal de la VM:

$sudo apt install -y build-essential dkms linux-headers-$(uname -r)

Herramientas para compilar los módulos del kernel.

$sudo mount /dev/cdrom /mnt
$sudo sh /mnt/VBoxLinuxAdditions.run

Al final debe decir que los módulos se cargaron. Un aviso sobre el sistema de ventanas es normal.

$sudo reboot
10.4

Verificar el OpenGL

El juego renderiza con OpenGL. Este comando dice quién está haciendo el trabajo gráfico.

$sudo apt install -y mesa-utils
$glxinfo -B | grep -iE 'renderer|version'

Si el renderer dice SVGA3D o similar, la aceleración 3D funciona: el juego irá fluido. Si dice llvmpipe, el procesador dibuja todo por software: el juego funciona pero lento; aplica los ajustes del paso 10.7 al mínimo.

10.5

Instalar el Minecraft Launcher

Mojang publica su launcher oficial como paquete .deb para Debian y Ubuntu. Se hace desde una terminal del escritorio XFCE.

$cd /tmp && wget https://launcher.mojang.com/download/Minecraft.deb
$sudo apt install -y ./Minecraft.deb

apt instala también las dependencias que pida el paquete.

$minecraft-launcher &

También aparece en el menú de aplicaciones de XFCE → Juegos. Inicia sesión con la cuenta Microsoft que tiene la licencia de Java Edition.

10.6

Crear la instalación 1.12.2

El cliente debe ser exactamente de la misma versión que el servidor.

  1. En el launcher: Minecraft: Java Edition → pestaña Instalaciones → Nueva instalación.
  2. Nombre: Lab 1.12.2. Versión: release 1.12.2.
  3. Resolución: 1280 × 720. Una ventana más chica se renderiza más rápido.
  4. Más opciones → Argumentos JVM: cambia -Xmx2G por -Xmx1536M. El servidor ya ocupa 1 GB en la misma VM.
  5. Crear y después Jugar. La primera vez descarga el juego y su propio Java 8; tarda unos minutos.

11. Comprobar el servidor sin cliente

11.1

Consultar con mcstatus

Herramienta de Python que hace la misma consulta que la lista de servidores del juego. No necesita licencia ni escritorio, así que cualquier alumno puede comprobar su servidor o el de un compañero.

$sudo apt install -y python3-venv
$python3 -m venv ~/mcs

Un entorno virtual aísla la herramienta del Python del sistema, como en sus prácticas de Flask.

$~/mcs/bin/pip install mcstatus
$~/mcs/bin/mcstatus localhost:25565 status

Responde la versión (1.12.2), el MOTD, los jugadores conectados y la latencia. Cambia localhost por la IP de un compañero para probar su servidor.

12. Administrar desde la consola

12.1

Operador y ticks por segundo

Como servicio, el servidor no tiene consola interactiva. Para dar comandos, se detiene el servicio y se arranca a mano.

$sudo systemctl stop minecraft
$sudo -u minecraft bash -c 'cd /opt/minecraft && /usr/lib/jvm/temurin-8-jre-amd64/bin/java -Xms512M -Xmx1G -Dlog4j.configurationFile=log4j2_112-116.xml -jar server.jar nogui'

Consola del servidor (escribe sin diagonal)

op TuNombreDeJugador
list
debug start
debug stop
stop

op da permisos de administrador y list muestra quién está conectado. debug start, espera unos 30 segundos y debug stop: el resultado indica los ticks por segundo reales (deben ser 20). stop guarda y apaga.

12.2

Regresar al modo servicio

Después de stop, vuelve a iniciar el servicio.

$sudo systemctl start minecraft

13. Evidencias para el reporte

13.1

Capturar el tráfico

Con un compañero conectado, se capturan 20 paquetes. Compara con Luanti, que usa UDP.

$sudo apt install -y tcpdump
$sudo tcpdump -i any -n tcp port 25565 -c 20

Verás las banderas TCP ([S], [.], [P.]): la conexión se abre y cada paquete se confirma.

13.2

Consumo de recursos

Se mide cuánta CPU y memoria usa el proceso Java con jugadores conectados.

$ps -o pid,user,%cpu,%mem,rss,cmd -C java

RSS es la memoria real en KB. Mide con 0, 1 y 5 jugadores y compara.

13.3

Respaldo del mundo

El mundo vive en la carpeta world/. Se detiene el servidor para que no cambie mientras se copia.

$sudo systemctl stop minecraft
$sudo tar -czf ~/respaldo-mundo-$(date +%F).tar.gz -C /opt/minecraft world
$sudo systemctl start minecraft
