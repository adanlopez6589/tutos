Servidor de Minecraft Java en Debian 12

Referencia de laboratorio · Administración y Configuración Cliente/Servidor

Esta guía instala el servidor oficial de Minecraft Java Edition como servicio de Debian 12. Al final tendrás un servidor de videojuego escuchando en el puerto TCP 25565, administrado con systemd, al que tus compañeros podrán conectarse desde el laboratorio.

Es el mismo modelo que siguen los juegos en línea más jugados: un servidor autoritativo que calcula el estado de la partida y clientes que solo envían acciones y muestran el resultado.

Qué es un servidor de Minecraft Java

Minecraft Java Edition separa el juego en dos programas: el cliente, que cada jugador instala en su computadora y que renderiza el mundo, y el servidor (server.jar), que Mojang distribuye gratis y que calcula el estado real de la partida. El servidor es autoritativo: los clientes solo envían sus acciones y el servidor decide qué pasa.

server.jar
Programa servidor oficial de Mojang, escrito en Java.
TCP 25565
Puerto y protocolo predeterminados de Minecraft Java Edition.
Tick
Cada ciclo en que el servidor recalcula el mundo. Minecraft trabaja a 20 ticks por segundo.
EULA
Acuerdo de licencia de Mojang que hay que aceptar antes de arrancar el servidor.
Temurin
Distribución gratuita de OpenJDK del proyecto Eclipse Adoptium.

Antes de empezar

  • VM con Debian 12, al menos 2 CPU y 4 GB de RAM; el servidor usará 2 GB.
  • Conexión a internet en la VM para descargar Java y el servidor.
  • Para conectarse, cada jugador necesita Minecraft Java Edition con licencia. El servidor es gratis; el cliente no.
  • Si ya instalaste Tomcat, no hay conflicto: Tomcat sigue con OpenJDK 17 y Minecraft usará su propio Java 21 por ruta completa.

¿Por qué no basta el Java de Debian?

Debian 12 trae OpenJDK 17 en sus repositorios, el mismo que usaste para Tomcat. Las versiones actuales de Minecraft piden Java 21 o más nuevo, así que agregaremos el repositorio oficial de Adoptium con su llave GPG, igual que se hace con cualquier software externo.

1. Actualizar el sistema

1.1

Actualizar e instalar herramientas

Se actualizan los paquetes y se instalan las utilidades para descargar archivos y leer JSON.

$sudo apt update
$sudo apt upgrade -y
$sudo apt install -y wget curl jq gpg

jq sirve para leer archivos JSON desde la terminal; lo usaremos para consultar la información oficial de Mojang.

2. Consultar la versión y el Java que necesita

2.1

Versión más reciente

Mojang publica un manifiesto JSON con todas las versiones. Este comando muestra la última versión estable.

$curl -fsSL https://piston-meta.mojang.com/mc/game/version_manifest_v2.json | jq -r '.latest.release'

Muestra el número de la versión estable actual. Anótalo para tu reporte: el cliente debe usar la misma versión.

2.2

Java requerido

Cada versión indica qué versión mayor de Java necesita. Se guardan dos variables que usaremos en el paso 5.

$LATEST=$(curl -fsSL https://piston-meta.mojang.com/mc/game/version_manifest_v2.json | jq -r '.latest.release')
$VERSION_URL=$(curl -fsSL https://piston-meta.mojang.com/mc/game/version_manifest_v2.json | jq -r --arg V "$LATEST" '.versions[] | select(.id == $V) | .url')
$curl -fsSL "$VERSION_URL" | jq '.javaVersion.majorVersion'

Si responde 21, sigue la guía tal cual. Si responde otro número (por ejemplo 25), cambia 21 por ese número en los pasos 3 y 7.

⚠ Las variables LATEST y VERSION_URL solo existen en esta sesión de terminal. Si la cierras, repite el paso 2.2 antes del paso 5.

3. Instalar Java 21 (Temurin)

3.1

Agregar el repositorio de Adoptium

Primero se importa la llave GPG con la que Adoptium firma sus paquetes y después se registra su repositorio para Debian 12 (bookworm).

$wget -qO - https://packages.adoptium.net/artifactory/api/gpg/key/public | gpg --dearmor | sudo tee /etc/apt/trusted.gpg.d/adoptium.gpg > /dev/null

La llave permite que apt verifique que los paquetes realmente vienen de Adoptium.

$echo "deb https://packages.adoptium.net/artifactory/deb bookworm main" | sudo tee /etc/apt/sources.list.d/adoptium.list
3.2

Instalar el JRE

Para ejecutar el servidor basta el JRE (entorno de ejecución); no hace falta el JDK completo.

$sudo apt update
$sudo apt install -y temurin-21-jre
3.3

Verificar la ruta de Java 21

Se comprueba dónde quedó instalado. Esa ruta completa se usará en el servicio.

$ls /usr/lib/jvm/

Debe aparecer temurin-21-jre-amd64. Si ya tenías Tomcat, también verás la carpeta de OpenJDK 17.

$/usr/lib/jvm/temurin-21-jre-amd64/bin/java -version

Resultado esperado: openjdk version "21…" y la palabra Temurin.

4. Crear el usuario del servicio

4.1

Usuario minecraft

Como con Tomcat, el servidor no corre como root: si alguien explotara una falla del juego, solo tendría los permisos de este usuario.

$sudo useradd -r -m -U -d /opt/minecraft -s /bin/false minecraft

-r crea una cuenta de sistema, -d /opt/minecraft la usa como carpeta del servidor y -s /bin/false impide iniciar sesión con ella.

5. Descargar el servidor

5.1

Descargar server.jar

Del JSON de la versión se obtiene la dirección oficial del servidor y se descarga directo a /opt/minecraft como el usuario minecraft.

$SERVER_URL=$(curl -fsSL "$VERSION_URL" | jq -r '.downloads.server.url')
$sudo -u minecraft curl -fLo /opt/minecraft/server.jar "$SERVER_URL"

sudo -u minecraft hace que el archivo nazca con el dueño correcto, sin necesidad de chown.

$ls -lh /opt/minecraft/

Debe aparecer server.jar con un tamaño aproximado de 50 a 60 MB.

6. Primer arranque y EULA

6.1

Arranque de prueba

La primera ejecución crea los archivos de configuración y se detiene sola, porque todavía no se ha aceptado la licencia.

$sudo -u minecraft bash -c 'cd /opt/minecraft && /usr/lib/jvm/temurin-21-jre-amd64/bin/java -Xms1G -Xmx2G -jar server.jar nogui'

-Xms1G es la memoria inicial y -Xmx2G la máxima. nogui evita que intente abrir una ventana: en un servidor no hay entorno gráfico.

6.2

Aceptar la EULA

El servidor no arranca hasta que el archivo eula.txt diga true. Al cambiarlo aceptas los términos de Mojang (minecraft.net/eula).

$sudo sed -i 's/eula=false/eula=true/' /opt/minecraft/eula.txt
$cat /opt/minecraft/eula.txt

La última línea debe decir eula=true.

7. Configurar y crear el servicio systemd

7.1

Ajustar server.properties

Archivo principal de configuración del servidor. Busca y cambia solo estas líneas; deja el resto igual.

$sudo nano /opt/minecraft/server.properties

/opt/minecraft/server.properties (solo las líneas a revisar)

motd=Servidor del laboratorio · Politécnica
max-players=20
gamemode=survival
difficulty=normal
online-mode=true
white-list=false
server-port=25565
view-distance=8

online-mode=true exige cuentas con licencia: no lo cambies a false. view-distance=8 reduce la carga de la VM.

7.2

Archivo del servicio

Igual que con Tomcat, se le indica a systemd cómo iniciar el servidor. La diferencia: aquí Java corre en primer plano, por eso no se usa Type=forking.

$sudo nano /etc/systemd/system/minecraft.service

/etc/systemd/system/minecraft.service

[Unit]
Description=Servidor de Minecraft Java
After=network.target

[Service]
User=minecraft
Group=minecraft
WorkingDirectory=/opt/minecraft
ExecStart=/usr/lib/jvm/temurin-21-jre-amd64/bin/java -Xms1G -Xmx2G -jar server.jar nogui
Restart=on-failure
SuccessExitStatus=0 143

[Install]
WantedBy=multi-user.target

ExecStart usa la ruta completa de Java 21 para no depender del Java predeterminado. SuccessExitStatus=143 indica que salir por la señal de detener (SIGTERM) es normal; el servidor guarda el mundo antes de cerrar.

7.3

Activar el servicio

Recargar systemd, iniciar el servidor y habilitarlo al arranque.

$sudo systemctl daemon-reload
$sudo systemctl enable --now minecraft

--now lo inicia en este momento además de habilitarlo.

8. Abrir el puerto

8.1

Cortafuegos

Se permite el tráfico TCP al puerto 25565. Si ufw está activo, asegúrate de no cerrar SSH.

$sudo ufw allow OpenSSH
$sudo ufw allow 25565/tcp
$sudo ufw status
8.2

VM en NAT (laboratorios sin DHCP)

Si tu VM está en NAT, como en la práctica de correo, hay que reenviar el puerto desde VirtualBox.

  • VirtualBox → Configuración de la VM → Red → Avanzadas → Reenvío de puertos.
  • Nueva regla: protocolo TCP, puerto anfitrión 25565, puerto invitado 25565.
  • Los compañeros se conectan a la IP de la computadora anfitriona, no a la de la VM.

Si tu VM está en modo puente (bridge), no necesitas este paso: se usa directamente la IP de la VM.

9. Verificar el servicio

9.1

Estado, puerto y bitácora

Confirmar que el servidor está activo, escuchando en TCP 25565, y seguir su bitácora en vivo.

$sudo systemctl status minecraft --no-pager

Resultado esperado: active (running).

$sudo ss -tlnp | grep ':25565 '

Debe aparecer una línea LISTEN con :25565 del proceso java.

$sudo journalctl -u minecraft -f

Espera la línea Done (…s)! For help, type "help": el mundo terminó de generarse. Sal con Ctrl+C; el servidor sigue corriendo.

10. Conectarse desde un cliente

10.1

IP del servidor

Obtén la IP de la VM para compartirla con tus compañeros.

$ip -br a

Usa la IP de la interfaz enp0s3 (o similar). En NAT, usa la IP de la computadora anfitriona.

10.2

Agregar el servidor en Minecraft

En una computadora con Minecraft Java Edition de la misma versión que el servidor.

  1. Abrir Minecraft Java Edition → Multijugador.
  2. Agregar servidor: nombre libre y en dirección la IP_DE_TU_VM.
  3. Si el ícono aparece en verde con la cantidad de jugadores, el servidor responde. Entrar con Unirse al servidor.

11. Administrar desde la consola (opcional)

11.1

Dar permisos de operador

Como servicio, el servidor no tiene consola interactiva. Para dar comandos, se detiene el servicio y se arranca a mano.

$sudo systemctl stop minecraft
$sudo -u minecraft bash -c 'cd /opt/minecraft && /usr/lib/jvm/temurin-21-jre-amd64/bin/java -Xms1G -Xmx2G -jar server.jar nogui'

Consola del servidor (escribe sin diagonal)

op TuNombreDeJugador
list
tick query
stop

op da permisos de administrador, list muestra quién está conectado, tick query muestra los ticks por segundo reales (deben ser 20) y stop guarda y apaga.

11.2

Regresar al modo servicio

Después de stop, vuelve a iniciar el servicio.

$sudo systemctl start minecraft

12. Evidencias para el reporte

12.1

Capturar el tráfico

Con un compañero conectado, se capturan 20 paquetes. Compara con Luanti, que usa UDP.

$sudo apt install -y tcpdump
$sudo tcpdump -i any -n tcp port 25565 -c 20

Verás las banderas TCP ([S], [.], [P.]): la conexión se abre y cada paquete se confirma.

12.2

Consumo de recursos

Se mide cuánta CPU y memoria usa el proceso Java con jugadores conectados.

$ps -o pid,user,%cpu,%mem,rss,cmd -C java

RSS es la memoria real en KB. Repite la medición con 1 y con 5 jugadores y compara.

12.3

Respaldo del mundo

El mundo vive en la carpeta world/. Se detiene el servidor para que no cambie mientras se copia.

$sudo systemctl stop minecraft
$sudo tar -czf ~/respaldo-mundo-$(date +%F).tar.gz -C /opt/minecraft world
$sudo systemctl start minecraft

13. Diagnóstico

13.1

Errores comunes

Síntoma y qué revisar.

SíntomaQué revisar
UnsupportedClassVersionErrorLa versión de Minecraft pide un Java más nuevo. Revisa el paso 2.2 e instala ese Temurin; cambia la ruta en el servicio.
You need to agree to the EULAeula.txt sigue en false. Repite el paso 6.2.
status: failedRevisa la bitácora con los comandos de abajo. Suele ser la ruta de Java o permisos de /opt/minecraft.
Permission deniedLa carpeta debe ser del usuario minecraft: sudo chown -R minecraft:minecraft /opt/minecraft.
OutOfMemoryErrorLa VM tiene poca RAM o -Xmx es muy alto. Deja al menos 1 GB libre para Debian.
El cliente dice «Connection refused»El servidor aún no termina de arrancar, el puerto no está abierto en ufw o falta el reenvío NAT (paso 8).
Outdated client / Outdated serverEl cliente y el servidor deben ser de la misma versión. En el lanzador elige la versión del paso 2.1.
Failed to verify usernameonline-mode=true necesita que el servidor tenga internet y que el jugador use una cuenta con licencia.
$sudo journalctl -u minecraft -n 50 --no-pager
$sudo tail -n 30 /opt/minecraft/logs/latest.log

Para revisar el servicio en cualquier momento: sudo systemctl status minecraft. Bitácora del juego: /opt/minecraft/logs/latest.log.
