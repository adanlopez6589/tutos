Guía Paso a Paso: Instalación de Nextcloud en LEMP con PostgreSQL y Nginx en Debian

1. Instalar dependencias

1.1
sudo apt update && sudo apt upgrade -y
1.2
sudo apt install nginx php php-fpm php-pgsql php-cli php-curl php-gd php-xml php-zip php-mbstring php-intl php-bcmath php-imagick php-gmp unzip curl wget gnupg2 -y

2. Instalar y configurar PostgreSQL

2.1
sudo apt install postgresql -y
2.2
sudo -u postgres psql

Dentro de PostgreSQL ejecuta:

2.3.1
CREATE DATABASE nextcloud;
2.4.1
CREATE USER nextclouduser WITH PASSWORD 'tu_password_segura';
2.5.1
GRANT ALL PRIVILEGES ON DATABASE nextcloud TO nextclouduser;
2.5.2
\c nextcloud
2.5.3
GRANT ALL PRIVILEGES ON SCHEMA public TO nextclouduser;
2.6.1
\q

2.7 Configuración opcional de red (IPv4/IPv6)

2.7.1
sudo nano /etc/postgresql/14/main/postgresql.conf
2.7.4
sudo systemctl restart postgresql

3. Descargar Nextcloud y moverlo

3.1
cd /tmp
3.2
wget https://download.nextcloud.com/server/releases/latest.zip
3.3
unzip latest.zip
3.4
sudo mv nextcloud /var/www/html/
3.5
cd /var/www/html/
3.6
sudo chown -R www-data:www-data nextcloud
3.7
sudo chmod -R 755 nextcloud

4. Configurar Nginx

4.1
sudo systemctl stop apache2
4.2
sudo nano /etc/nginx/sites-available/nextcloud

Contenido del archivo:

server {
    listen 80;
    server_name localhost;

    root /var/www/html;
    index index.php index.html;

    client_max_body_size 512M;
    fastcgi_buffers 64 4K;

    access_log /var/log/nginx/nextcloud_access.log;
    error_log /var/log/nginx/nextcloud_error.log;

    location /nextcloud/ {
        try_files $uri $uri/ /nextcloud/index.php$request_uri;
    }

    location ~ ^/nextcloud/.*\.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~* ^/nextcloud/\.(?:css|js|woff2?|svg|gif|map)$ {
        try_files $uri /nextcloud/index.php$request_uri;
        access_log off;
        expires 6M;
        add_header Cache-Control "public";
    }

    location ~ ^/nextcloud/\.ht {
        deny all;
    }
}
4.4.1
sudo ln -s /etc/nginx/sites-available/nextcloud /etc/nginx/sites-enabled/
4.5.1
sudo nginx -t
4.6.1
sudo systemctl restart nginx

5. Configurar PHP

5.1
sudo nano /etc/php/8.2/fpm/php.ini

Modificar los siguientes parámetros dentro de php.ini:

memory_limit = 512M
upload_max_filesize = 512M
post_max_size = 512M
max_execution_time = 360
5.3.1
sudo systemctl restart php8.2-fpm

6. Finalizar instalación

6.1 Acceder a:

http://localhost/nextcloud/

6.2 Configurar:

  • 6.2.1 Usuario: nextclouduser
  • 6.2.2 Contraseña: tu_password_segura
  • 6.2.3 Base de datos: nextcloud
  • 6.2.4 Servidor: localhost
