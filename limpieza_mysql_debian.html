Limpieza de MariaDB/MySQL e instalación limpia

Referencia de laboratorio · Administración y Configuración Cliente/Servidor

Esta guía deja el sistema sin rastros de MariaDB o MySQL y después instala MySQL oficial desde el repositorio de Oracle. Síguela en orden: primero la limpieza completa, luego la instalación.

1. Diferencia clave

MariaDB
usa paquetes como mariadb-server y mariadb-client.
MySQL oficial
usa paquetes como mysql-community-server.
En común
ambos suelen usar /etc/mysql, /var/lib/mysql y el puerto 3306.

2. Limpieza total recomendada

2.1

Detener servicios

Detener MySQL y MariaDB antes de quitar los paquetes.

$sudo systemctl stop mysql
$sudo systemctl stop mariadb
2.2

Eliminar paquetes relacionados

Purgar paquetes de MariaDB y MySQL junto con su configuración.

$sudo apt purge -y mariadb-server mariadb-client mariadb-common mariadb-server-core* mariadb-client-core*

Paquetes de MariaDB.

$sudo apt purge -y mysql-server mysql-client mysql-common mysql-server-core* mysql-client-core*

Paquetes de MySQL.

2.3

Eliminar dependencias huérfanas

Limpiar paquetes innecesarios y la caché de apt.

$sudo apt autoremove -y
$sudo apt autoclean
2.4

Borrar archivos residuales

Eliminar configuración, datos y bitácoras que apt no borra.

⚠ /var/lib/mysql contiene las bases de datos. Si hay algo que conservar, respáldalo antes.

$sudo rm -rf /etc/mysql
$sudo rm -rf /var/lib/mysql
$sudo rm -rf /var/log/mysql
$sudo rm -rf /var/run/mysqld

Opcional: eliminar el directorio de ejecución.

2.5

Verificar que no quede nada

Comprobar paquetes instalados. Si no devuelve nada, la limpieza terminó.

$dpkg -l | grep -i mysql
$dpkg -l | grep -i mariadb

3. Problema común

Si antes intentaste instalar MySQL 8 en Debian 12 o Debian 13, es común encontrar errores de firma GPG o conflictos con repositorios anteriores. Por eso conviene hacer la limpieza completa antes de instalar el repositorio oficial de MySQL.

4. Instalación limpia de MySQL oficial

4.1

Instalar el repositorio

Descargar e instalar mysql-apt-config desde /tmp.

$cd /tmp

Descarga en una carpeta temporal para no dejar el .deb en tu home.

$wget https://dev.mysql.com/get/mysql-apt-config_0.8.36-1_all.deb
$sudo dpkg -i mysql-apt-config_0.8.36-1_all.deb

Durante la instalación del paquete, selecciona la versión de MySQL que deseas habilitar, por ejemplo MySQL 8.0 o la rama estable que necesites.

4.2

Actualizar repositorios

Actualizar los índices de paquetes para que apt vea el repo nuevo.

$sudo apt update
4.3

Instalar MySQL

Instalar el servidor MySQL.

$sudo apt install mysql-server
4.4

Verificar instalación

Comprobar la versión instalada.

$mysql --version

Para ver el estado del servidor después de instalar: sudo systemctl status mysql.
