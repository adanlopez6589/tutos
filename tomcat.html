Instalación de Apache Tomcat en Debian 12

Práctica de laboratorio para instalar y probar un servidor de aplicaciones Java.

¿Qué es Apache Tomcat?

Apache Tomcat es un servidor de aplicaciones ligero para Java. Su función principal es ejecutar aplicaciones web desarrolladas con tecnologías Java, especialmente Servlets y JSP.

Conceptos clave

  • Servidor de aplicaciones: software que ejecuta la lógica de una aplicación web y responde a las solicitudes de los clientes.
  • Servlet: clase Java que recibe una petición web, la procesa en el servidor y genera una respuesta, por ejemplo HTML, JSON o texto.
  • JSP: JavaServer Pages. Tecnología que permite crear páginas web dinámicas usando HTML combinado con código Java.
  • WAR: Web Application Archive. Archivo empaquetado que contiene una aplicación web Java lista para desplegarse en Tomcat.

Características de Tomcat

  • Es open source y ampliamente utilizado en ambientes educativos y empresariales.
  • Permite desplegar aplicaciones Java empaquetadas en formato .war.
  • Puede ejecutarse como servicio del sistema en Linux mediante systemd.
  • Trabaja comúnmente en el puerto 8080.
  • Puede integrarse con Nginx o Apache HTTP Server mediante proxy reverso.
  • Es útil para comprender la arquitectura cliente-servidor en aplicaciones web.

¿Por qué es importante instalarlo actualmente?

Instalar Tomcat sigue siendo importante porque permite entender cómo se despliegan aplicaciones Java en un servidor real. Aunque actualmente muchos proyectos modernos usan Spring Boot con servidor embebido, Tomcat continúa siendo una base técnica relevante para comprender el despliegue tradicional de aplicaciones Java, la administración de servicios en Linux y la relación entre servidor web, servidor de aplicaciones y aplicación web.

1. Actualizar sistema

Antes de instalar servicios, se actualizan los repositorios y paquetes del sistema para evitar errores por dependencias antiguas.

1.1 sudo apt update && sudo apt upgrade -y

2. Instalar Java

Tomcat necesita Java para ejecutarse, porque las aplicaciones que atiende están desarrolladas con esta tecnología.

2.1 sudo apt install default-jdk -y

Verifica que Java quedó instalado correctamente.

2.2 java -version

3. Crear usuario del sistema para Tomcat

Se crea un usuario llamado tomcatuser. Este usuario será utilizado por el servicio de Tomcat para ejecutarse de forma más segura, evitando que el servicio trabaje directamente como root.

3.1 sudo useradd -m -U -d /opt/tomcat -s /bin/false tomcatuser

4. Descargar Apache Tomcat

Se descarga Tomcat desde el sitio oficial de Apache. Primero se cambia al directorio temporal /tmp para trabajar con el archivo descargado.

4.1 cd /tmp
4.2 wget https://downloads.apache.org/tomcat/tomcat-10/v10.1.28/bin/apache-tomcat-10.1.28.tar.gz

5. Instalar Tomcat en /opt/tomcat

Se crea la carpeta de instalación y se extrae el contenido del archivo comprimido dentro de /opt/tomcat. Esta ubicación es común para instalar aplicaciones adicionales del sistema.

5.1 sudo mkdir /opt/tomcat
5.2 sudo tar -xzf apache-tomcat-10.1.28.tar.gz -C /opt/tomcat --strip-components=1

6. Asignar permisos y propietario

Se asigna la carpeta de Tomcat al usuario tomcatuser y se otorgan permisos de ejecución a los scripts de arranque y apagado.

6.1 sudo chown -R tomcatuser:tomcatuser /opt/tomcat
6.2 sudo chmod +x /opt/tomcat/bin/*.sh

7. Crear el servicio systemd para Tomcat

En este punto se debe crear un archivo nuevo llamado /etc/systemd/system/tomcat.service y agregar dentro los parámetros indicados. Si el archivo ya existiera, entonces se edita.

7.1 sudo nano /etc/systemd/system/tomcat.service

Agregar el siguiente contenido dentro del archivo:

[Unit]
Description=Apache Tomcat
After=network.target

[Service]
Type=forking
User=tomcatuser
Group=tomcatuser
Environment=JAVA_HOME=/usr/lib/jvm/default-java
Environment=CATALINA_HOME=/opt/tomcat
Environment=CATALINA_BASE=/opt/tomcat
ExecStart=/opt/tomcat/bin/startup.sh
ExecStop=/opt/tomcat/bin/shutdown.sh

[Install]
WantedBy=multi-user.target

Después de guardar el archivo, se recargan los servicios de systemd para que Debian reconozca el nuevo servicio de Tomcat.

7.2 sudo systemctl daemon-reload

Se inicia el servicio de Tomcat.

7.3 sudo systemctl start tomcat

Se habilita Tomcat para que inicie automáticamente cuando arranque el sistema.

7.4 sudo systemctl enable tomcat

8. Verificar el servicio

Se revisa el estado del servicio para confirmar que Tomcat está activo y sin errores.

8.1 sudo systemctl status tomcat

9. Probar Tomcat en el navegador

Si Tomcat está funcionando correctamente, se mostrará la página inicial del servidor en el navegador.

9.1 http://localhost:8080
