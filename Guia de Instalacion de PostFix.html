Guía: Configurar Postfix para el envío de correos desde Nextcloud en Localhost

1. Instalar Postfix

sudo apt update
sudo apt install postfix mailutils -y

2. Configurar Postfix (modo básico)

Durante la instalación selecciona:

  • Tipo de configuración: Sitio de Internet
  • Nombre del sistema de correo: localhost

3. Probar el envío de correos entre usuarios locales

Este comando muestra solo los usuarios humanos del sistema (UID mayor o igual a 1000).

awk -F: '$3 >= 1000 {print $1}' /etc/passwd

Este comando crea un nuevo usuario local llamado juan si no existe ninguno.

sudo adduser juan

Este comando envía un correo local al usuario juan.

echo "Este es un mensaje de prueba" | mail -s "Correo de prueba" juan

Este comando permite leer el correo como si fueras el usuario juan.

sudo -u juan mail

También puedes usar este comando si tú mismo recibiste el mensaje de prueba.

mail

Resumen de comandos útiles dentro de mail

  • h — Ver la bandeja de entrada (encabezados de todos los mensajes).
  • 1, 2, etc. — Leer un mensaje específico por su número.
  • n — Pasar al siguiente mensaje.
  • p — Volver a mostrar el mensaje actual.
  • d N — Marcar para eliminación el mensaje número N (por ejemplo, d 1).
  • u N — Desmarcar el mensaje N si fue marcado con d.
  • q — Salir del programa y eliminar los mensajes marcados.
  • x — Salir del programa sin eliminar ningún mensaje ni guardar cambios.

4. Configurar Nextcloud para usar Postfix

En la interfaz de Nextcloud, accede como administrador y dirígete a:

Configuración > Administración > Configuración básica

Completa los campos de correo así:

  • Modo de envío: SMTP
  • Servidor: localhost
  • Puerto: 25
  • Seguridad: Ninguna
  • Autenticación: Sin autenticación

5. Verificar el envío

Usa la opción "Enviar correo de prueba" en la misma sección de configuración de Nextcloud para validar la conexión con Postfix.

Notas adicionales

  • Si deseas enviar correos fuera de localhost, deberás configurar Postfix con un servidor de retransmisión externo (SMTP relay como Gmail, Mailgun, etc.).
  • Para ver los registros de correo: /var/log/mail.log

6. Configurar Postfix como Relay SMTP usando Gmail (cuenta institucional @alumnos.udg.mx)

Este método permite que Postfix envíe correos usando la infraestructura de Gmail. Requiere:

  • Cuenta institucional de Google Workspace (@alumnos.udg.mx)
  • Verificación en dos pasos activada
  • Contraseña de aplicación generada desde la configuración de seguridad de la cuenta

Editar configuración de Postfix

Edita el archivo /etc/postfix/main.cf y agrega al final:

relayhost = [smtp.gmail.com]:587
smtp_use_tls = yes
smtp_sasl_auth_enable = yes
smtp_sasl_password_maps = hash:/etc/postfix/sasl_passwd
smtp_sasl_security_options = noanonymous
smtp_tls_CAfile = /etc/ssl/certs/ca-certificates.crt

Crear archivo de contraseñas

Reemplaza tuusuario@alumnos.udg.mx y tu_contraseña_app con tus datos reales:

sudo nano /etc/postfix/sasl_passwd
[smtp.gmail.com]:587 tuusuario@alumnos.udg.mx:tu_contraseña_app

Proteger, compilar y reiniciar

sudo postmap /etc/postfix/sasl_passwd
sudo chown root:root /etc/postfix/sasl_passwd*
sudo chmod 600 /etc/postfix/sasl_passwd*
sudo systemctl restart postfix

Verifica el log para ver si el correo fue enviado

tail -f /var/log/mail.log

Desde Nextcloud puedes usar el botón "Enviar correo de prueba" para verificar que funcione correctamente.
