1. Objetivos y topología

En esta práctica vas a:

  • Parte 1: Configurar nombre, contraseñas y banner en los switches S1 y S2, y guardar la configuración.
  • Parte 2: Asignar dirección IP a las PCs.
  • Parte 3: Darle una IP de administración a cada switch (interfaz VLAN 1).
  • Parte 4: Comprobar que todos los equipos se comunican con ping.

2. Antes de empezar: los modos de Cisco IOS

El sistema operativo de los switches y routers Cisco (IOS) funciona por niveles. Cada nivel permite ciertos comandos, y el prompt (el texto antes del cursor) indica en qué nivel estás.

S1> Modo usuario (EXEC) → solo consultas básicas │ enable S1# Modo privilegiado → show, copy, reload, ping │ configure terminal S1(config)# Configuración global → hostname, enable secret, banner │ line console 0 / interface vlan 1 S1(config-line)# Configuración de línea → password, login S1(config-if)# Configuración de interfaz → ip address, no shutdown
ComandoQué hace
enablePasa de modo usuario (>) a privilegiado (#).
configure terminalEntra a configuración global.
exitSube un nivel.
end o Ctrl+ZRegresa directo a modo privilegiado (#) desde cualquier submodo.
El prefijo "no" En IOS, escribir no antes de un comando lo cancela o deshace. Por ejemplo, no hostname regresa el nombre a Switch, y no shutdown enciende una interfaz.

3. Parte 1: Configuración básica de S1 y S2

Haz clic en S1 → pestaña CLI. Presiona Enter para obtener el prompt Switch>.

Paso 1 Asignar nombre al switch

Switch> enable
Switch# configure terminal
Switch(config)# hostname S1
S1(config)#

hostname cambia el nombre del dispositivo. El prompt cambia de inmediato a S1. Sirve para identificar en qué equipo estás trabajando, algo indispensable cuando hay muchos.

Paso 2 Contraseña de consola

S1(config)# line console 0
S1(config-line)# password cisco
S1(config-line)# login
S1(config-line)# exit
S1(config)#

¿Por qué line console 0?

La contraseña de consola no es global: se asigna a una línea de acceso específica. Este comando entra al modo de configuración del puerto de consola (donde se conecta el cable azul o rollover). El prompt cambia a (config-line)#.

ParteSignificado
lineConfigurar una línea de acceso al dispositivo
consoleEl tipo de línea: el puerto físico de consola
0Número de línea. Los switches tienen una sola consola, la 0

Otros tipos de línea: line vty 0 15 (acceso remoto por Telnet/SSH, 16 líneas virtuales) y line aux 0 (puerto auxiliar en algunos routers). Cada una se protege por separado.

¿Por qué password y luego login?

password cisco solo guarda la contraseña. login hace que el switch la pida al conectarse. Son complementarios.

ConfiguraciónResultado al conectarse
password sin loginEntra directo, no pide nada
password + loginMuestra Password: y solo entra con la contraseña correcta
login sin passwordError: Login disabled on line 0, until 'password' is set

¿Por qué exit?

Regresa de (config-line)# a (config)#. El siguiente comando (enable secret) es global: afecta a todo el switch y no solo a la consola, por eso se escribe desde configuración global. Es una buena práctica para cerrar cada bloque de configuración.

Paso 2b Contraseña cifrada de modo privilegiado

S1(config)# enable secret class

Protege el paso de modo usuario (S1>) a modo privilegiado (S1#). Es la segunda capa de seguridad: la consola protege la entrada al equipo y el enable protege los comandos de administración.

enable secret vs enable password

enable password classenable secret class
Cómo se guardaTexto plano, cualquiera la leeHash MD5 (tipo 5), no reversible
En show running-configenable password classenable secret 5 $1$mERr$9cTj...
EstadoObsoletoRecomendado

Si se configuran los dos, siempre gana enable secret.

¿Y qué es service password-encryption?

Cifra las contraseñas que están en texto plano (consola, vty y enable password) con tipo 7. Es un cifrado débil que se revierte fácilmente con herramientas en línea; solo evita que se lean a simple vista. No sustituye a enable secret. No se pide en esta práctica.

line con 0
 password 7 0822455D0A16       ← tipo 7 (reversible)
enable secret 5 $1$mERr$...    ← tipo 5 (hash, no reversible)

Paso 3 Verificar las contraseñas

S1(config)# end
S1# show running-config

Observa:

  • enable secret 5 $1$...: la contraseña de enable aparece cifrada.
  • En line con 0, la línea password cisco aparece en texto plano.

Para probarlo, escribe exit hasta salir de la sesión, presiona Enter y verifica que pida la contraseña de consola y después la de enable.

Paso 4 Banner MOTD

S1# configure terminal
S1(config)# banner motd #Authorized access only.#
S1(config)# end

Un banner es un mensaje de texto que el switch muestra automáticamente cuando alguien se conecta, antes de pedir la contraseña. Se usa como aviso legal de acceso restringido.

ParteSignificado
bannerConfigurar un mensaje
motdMessage Of The Day, el mensaje del día
# … #Delimitadores: marcan el inicio y el fin del texto. Puede ser cualquier carácter que no aparezca dentro del mensaje (#, $, %)

Así se ve al conectarse:

Authorized access only.

User Access Verification

Password:
¿Por qué un aviso y no "Bienvenido"? Un mensaje de bienvenida puede interpretarse como una invitación a entrar. El banner debe advertir y no debe revelar información útil para un atacante (modelo del equipo, ubicación, empresa).

En show running-config aparece como banner motd ^CAuthorized access only.^C. IOS muestra el delimitador como ^C, sin importar cuál usaste.

Paso 5 Guardar la configuración en NVRAM

S1# copy running-config startup-config
Destination filename [startup-config]?   ← presiona Enter
Building configuration...
[OK]                                     ← se guardó

¿Qué es la NVRAM y por qué hay que guardar?

NVRAM (Non-Volatile RAM) es una memoria que conserva su contenido aunque se apague el equipo. El switch maneja dos configuraciones:

running-configstartup-config
Dónde viveRAM (volátil)NVRAM (no volátil)
Qué esLa configuración activa ahoraLa que se carga al encender
Cuándo cambiaCon cada comando que escribesSolo cuando la guardas
Al apagar o reiniciarSe pierdeSe conserva

Todo lo que configuraste vive en RAM. Si el switch se reinicia sin guardar, arranca de nuevo como Switch> sin configuración.

Desglose del comando

copy   running-config   startup-config
 │          │                 │
acción   ORIGEN (RAM)     DESTINO (NVRAM)

La palabra que se refiere a la NVRAM es startup-config, que es un atajo de la ruta completa nvram:startup-config.

  • Se ejecuta en modo privilegiado (S1#). Si estás en (config)#, sal primero con end.
  • Atajos equivalentes: copy run start, write memory, wr.
  • Para comprobarlo: show startup-config. Si aparece startup-config is not present, no se guardó.

5. La máscara de red

La máscara es un número de 32 bits que indica qué parte de la IP identifica a la red y qué parte identifica al equipo (host).

IP:       192 . 168 .   1  .  1
Máscara:  255 . 255 . 255  .  0
          └──── RED ─────┘  └HOST┘

Todos los equipos de la práctica comparten 192.168.1, así que están en la misma red y se comunican sin router.

¿Por qué 255.255.255.0?

255.255.255.0 = 11111111.11111111.11111111.00000000
                └────── 24 bits de red ──────┘└ 8 host ┘
  • Los bits en 1 marcan la red. Al ser 24 bits, también se escribe /24.
  • Con 8 bits de host hay 2⁸ = 256 direcciones, pero 2 están reservadas: la .0 es la dirección de red y la .255 es el broadcast. Quedan 254 hosts utilizables (fórmula: 2ⁿ − 2).
  • Es fácil de leer y alcanza para redes pequeñas, por eso es la más usada en casas, oficinas y laboratorios.

Otras máscaras

No siempre es /24. Cada octeto de una máscara solo puede valer 0, 128, 192, 224, 240, 248, 252, 254 o 255, porque los bits en 1 deben ir seguidos a la izquierda.

MáscaraCIDRHosts útilesUso típico
255.0.0.0/816,777,214Redes enormes
255.255.0.0/1665,534Campus o empresas grandes
255.255.255.0/24254Casa, oficina, laboratorio
255.255.255.128/25126Dividir una /24 en 2
255.255.255.192/2662Un laboratorio de cómputo
255.255.255.224/2730Área pequeña
255.255.255.252/302Enlace entre 2 routers
Error frecuente Todos los equipos de una misma red deben tener la misma máscara. Si dos equipos tienen distinta parte de red (por ejemplo 192.168.1.1 y 192.168.2.1 con /24), no se comunican sin un router.

El tema completo (binario y subneteo) se ve en los Módulos 5 y 11 de ITN.

6. Parte 3: Interfaz de administración del switch (SVI)

¿Qué es una interfaz VLAN?

Es una interfaz virtual del switch (no existe físicamente) a la que se le asigna una IP. Su nombre técnico es SVI (Switch Virtual Interface).

Los puertos físicos de un switch de capa 2 (Fa0/1, Fa0/2…) no pueden tener IP. Para que el switch responda a un ping o acepte conexiones remotas (Telnet/SSH), necesita una IP, y esa IP va en la SVI.

Sin SVICon SVI
¿Reenvía tráfico entre PCs?SíSí
¿Responde a ping?NoSí
¿Administración remota?No, solo por consolaSí

Se usa VLAN 1 porque es la VLAN por defecto: todos los puertos pertenecen a ella de fábrica. En redes reales se recomienda una VLAN de administración dedicada (por ejemplo, VLAN 99); eso se ve en el curso SRWE.

Paso 1 Configurar la SVI en S1

S1> enable
Password: class
S1# configure terminal
S1(config)# interface vlan 1
S1(config-if)# ip address 192.168.1.253 255.255.255.0
S1(config-if)# no shutdown
S1(config-if)# end
S1# copy running-config startup-config

Paso 2 Configurar la SVI en S2

S2> enable
Password: class
S2# configure terminal
S2(config)# interface vlan 1
S2(config-if)# ip address 192.168.1.254 255.255.255.0
S2(config-if)# no shutdown
S2(config-if)# end
S2# copy running-config startup-config

¿Qué significa no shutdown?

shutdown apaga una interfaz y no shutdown la enciende. La SVI de VLAN 1 viene apagada de fábrica; sin este comando tiene IP pero no responde.

%LINK-5-CHANGED: Interface Vlan1, changed state to up
%LINEPROTO-5-UPDOWN: Line protocol on Interface Vlan1, changed state to up
Tipo de interfazEstado de fábrica
SVI (interface vlan 1)Apagada, requiere no shutdown
Puertos físicos del switchEncendidos
Interfaces de routerApagadas, requieren no shutdown (Módulo 10)

7. Parte 4: Verificar la conectividad de extremo a extremo

Desde PC1:

C:\> ping 192.168.1.2      ← PC2
C:\> ping 192.168.1.253    ← S1
C:\> ping 192.168.1.254    ← S2

Desde PC2:

C:\> ping 192.168.1.1
C:\> ping 192.168.1.253
C:\> ping 192.168.1.254

¿Cómo se interpreta el resultado de ping?

ping envía mensajes ICMP Echo Request y el destino responde con ICMP Echo Reply. Si llega la respuesta, hay conectividad.

9. Errores comunes que bajan el porcentaje en Check Results

  1. Usar enable password en lugar de enable secret.
  2. Olvidar login en line console 0.
  3. Escribir mal el hostname (por ejemplo, s1 en minúsculas).
  4. Texto del banner distinto al que pide la práctica.
  5. No dar no shutdown en interface vlan 1.
  6. Máscara distinta en algún equipo.
  7. No guardar con copy running-config startup-config: varios ítems revisan la startup-config.
  8. Ejecutar copy desde (config)# en lugar de modo privilegiado.

11. Preguntas de repaso

1. ¿Qué pasa si configuras password cisco en la consola pero no escribes login?

La contraseña se guarda, pero el switch no la pide: cualquiera con cable de consola entra directo.

2. ¿Por qué se prefiere enable secret sobre enable password?

Porque guarda la contraseña como hash MD5 no reversible, mientras que enable password la deja en texto plano.

3. Configuraste todo, apagaste el switch y al encenderlo aparece Switch>. ¿Qué faltó?

Guardar con copy running-config startup-config. La configuración estaba solo en RAM y se perdió.

4. ¿Por qué PC1 hace ping a PC2 antes de configurar la SVI?

Porque el switch reenvía tramas con direcciones MAC; no necesita IP para conmutar. La SVI solo sirve para administrar el switch.

5. La SVI tiene IP pero no responde al ping. ¿Qué revisas primero?

Que se haya dado no shutdown. En show ip interface brief aparecería como administratively down.

6. ¿Cuántos hosts permite una red /24 y por qué?

254. Hay 8 bits de host (2⁸ = 256) menos la dirección de red (.0) y la de broadcast (.255).

7. Al hacer ping a S1 desde PC1 ves TTL=255. ¿Por qué no 128?

Porque el TTL lo pone quien responde. Los equipos Cisco inician en 255 y las PCs Windows en 128.

8. ¿Qué palabra del comando copy running-config startup-config se refiere a la NVRAM?

startup-config, que equivale a nvram:startup-config.
